# Code of Conduct

Nanquim adopts the **Contributor Covenant, version 2.1**, available at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>, as its code of conduct.

In short: be respectful, welcoming and constructive; harassment and discrimination of any kind are not tolerated in any project space (issues, pull requests, discussions, chat, events).

## Reporting
Report unacceptable behavior to the maintainers through the contact listed here.

> ⚠ The enforcement contact is still to be defined and MUST be filled in before the repository is made public.
